# Patches da versão 1.0.0

Use `scripts/prepare_sdk.ps1`. O patch consolidado aplica-se ao commit registrado em dependencies.json. Os patches antigos da base foram substituídos nesta árvore; a autoria e o histórico continuam preservados no Git. A alteração local de FFmpeg é aplicada separadamente. Os links do libmspack são expandidos no arquivo de fontes, sem mudar seu código.
